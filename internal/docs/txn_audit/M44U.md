## Corrections proposed

## Flags & suggestions (for the main agent / design report)
- **A. Cross-document recovery is pervasive.** 16 of 17 `carrying_value`s, and all 5 prior-year `sale_price`s, originate from FY2024/FY2023 ARs **not in the repo** → not independently verifiable here. If Phase-2 scope is "figures printed in *this* report," these should be re-checked against the cited external ARs or flagged as recovered.
- **B. 30 Tuas South Avenue 8: `carrying_value` (9,500,000) exactly equals `valuation` (9,500,000).** Plausible for a fair-value REIT (carrying at prior FY-end = last valuation), but the coincidence + external source (FY2024 AR p124) warrants a re-verify that carrying was not simply copied from the divestment-table valuation.
- **C. `carrying_value_currency = SGD` on Chee Wah / Subang 1 is consistent** with MLT's portfolio-statement convention (all portfolio/held-for-sale carrying values in this report are S$'000 — e.g. p173 held-for-sale S$47,102k). The **currency tag is fine**; but the underlying values (S$6,618k / S$9,265k) come from FY2023 AR p190 (not in repo) and at 31/03/2023 only a **combined** held-for-sale figure (S$14,956k) existed for the pair — per-property carrying is one balance-date older and not separable. Value unverifiable in-scope.
- **D. Xi'an `net_proceeds` label nuance:** the printed figure is "Net cash inflow on disposal, net of divestment costs" / "Proceeds from disposal of interests in a subsidiary, net of cash disposed" (a subsidiary-disposal cash figure reflecting deconsolidation), not a plain property net-sale-proceeds — but it *is* a net-of-cost figure, so mapping to `net_proceeds` is defensible.
- **E. Naming:** row "Kenyon" = property "8 Loyang Crescent" (report uses both names; p173 vs p24). Field name `sale_price` vs `gross_sale_price` used in other reports — normalize at load.
- **Recoverable / majority-disclose that we don't capture:** per-deal **Premium-to-Valuation %** (all current-FY deals, pp13–15); **fund-level divestment-gain distribution** amount (S$26,968,000) — strong DPU-boost datapoint; valuer name + valuation date (captured); stake — n/a (100% asset sales). Xi'an also discloses net-assets-disposed breakdown (Note 11).
