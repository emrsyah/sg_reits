- fn1: "entered into and completed **in FY 2025**" (p22, no date).

The disclosure is deliberately an **"average price"** across strata units with no single transaction date → `transaction_date` null is correct. ✓

## Suggestions / raw material for design report
- **DPU linkage — clean, explicit use-of-proceeds:** "The proceeds were used to **pare down debts**. The transactions are expected to be accretive to Suntec REIT's earnings as the achieved yields were lower than the current borrowing costs" (p22, line 793). **No distribution of divestment gains** to unitholders (no capital/special-distribution note found). `use = repay_debt`, `distributed_gain = false`.
- **Mixed-granularity row (key design issue):** the single row blends **single-unit** fields (amount 15,400 / carrying 13,126 / valuation 13,100 = the Nava Bharat unit) with a **2-unit FY-aggregate** context figure (net proceeds 30,554; profit 4,798). Two strata units were divested in FY2025 but only the Nava Bharat one is named/priced; the **second unit is under-disclosed** (no buyer/price/date) and not separately captured. A `deal_grain` / `is_aggregate` flag, or splitting aggregate vs per-unit money columns, would prevent silent over-attribution.
- **Coverage gaps:**
  - Second FY2025 strata divestment not separately capturable (report gives only aggregate net proceeds S$30,554k for both units).
  - Per-unit gain not disclosed (only Group aggregate S$4,798k) — do NOT derive.
  - Valuation method + valuation date (31-Dec-2024 report; income cap / DCF / direct comparison) disclosed (p22 fn2) but not captured.
  - "19.6% above book value" premium is disclosed as an **average**, not per-unit.
