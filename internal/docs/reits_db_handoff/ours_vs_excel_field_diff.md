## 3. How to read this

- **Sign/convention diffs** (minorities, perps, EBIT, EBITDA, interest, FFO, capex, free_cash_flow, net_cash_flow): expected — ours and Excel apply different documented conventions, not extraction errors. See `manual_vs_ours_parity.md` §3/§5.
- **Value diffs**: a genuine number gap. Where AR-verified (blind re-extraction / parsed reports), the verdict is in the `why` column — every settled case so far, **ours matches the AR** and the Excel is the outlier.
- Everything not listed in §2 is **exact** between ours and Excel.
